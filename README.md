
# Sistema de Gestión de Alquiler de Bicicletas

## Descripción del proyecto

Sistema desarrollado en Java para gestionar clientes, bicicletas y alquileres en un negocio turístico. Permite organizar la información y facilitar el control de los alquileres de bicicletas.

## Tecnologías utilizadas

- Java
- Apache NetBeans
- GitHub

## Funcionalidades

- Gestión de clientes.
- Registro y administración de bicicletas.
- Gestión de alquileres.
- Control de la información del sistema.

## Estructura del proyecto

El proyecto está organizado de la siguiente manera:

- **src:** contiene las clases y el código fuente del sistema.
- **nbproject:** contiene los archivos de configuración de NetBeans.
- **build.xml:** archivo utilizado para la compilación del proyecto.

## Instrucciones de ejecución

1. Descargar el proyecto desde el repositorio de GitHub.
2. Extraer el archivo ZIP.
3. Abrir Apache NetBeans.
4. Seleccionar **File → Open Project**.
5. Buscar y seleccionar la carpeta del proyecto.
6. Ejecutar el programa desde NetBeans.

## Requisitos

- Java JDK instalado.
- Apache NetBeans instalado.

## Control de versiones

El código fuente y la documentación del proyecto se encuentran alojados en GitHub. Se utiliza el control de versiones para mantener un historial de los cambios realizados.

# Sistema de Gestión de Alquiler de Bicicletas

## Descripción del proyecto

Sistema desarrollado en Java para gestionar clientes, bicicletas y alquileres en un negocio turístico. Permite organizar la información y facilitar el control de los alquileres de bicicletas.

## Tecnologías utilizadas

- Java
- Apache NetBeans
- GitHub

## Funcionalidades

- Gestión de clientes.
- Registro y administración de bicicletas.
- Gestión de alquileres.
- Control de la información del sistema.
